kettleandcloud-trends

Public view of the weekly trend digest at
https://shreyan735-red.github.io/kettleandcloud-trends/

`index.html` is generated by `trend-tools/` (see that folder's README).
To redeploy a fresh run, from `trend-tools/`:

    cp digests/trends-dashboard.html site/index.html
    cd site && git commit -am "refresh digest" && git push
